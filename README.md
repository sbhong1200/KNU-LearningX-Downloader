KNU-DOWNLOADER
경북대학교(KNU) Canvas 강의 영상 다운로드 도구

설치 방법
1. 크롬 주소창에 `chrome://extensions` 접속
2. 우측 상단 "개발자 모드" ON
3. [압축해제된 확장 프로그램 로드] 클릭 -> `knu-downloader-ver2' 폴더 선택

주의 사항 (필독)
- 영상 재생 필수: 반드시 강의 영상을 먼저 재생해야 주소가 감지됩니다. (재생을 안 하면 다운로드 버튼이 뜨지 않습니다.)
- 동영상 다운 중에 크롬 창 터치 금지: 동영상 다운 중에 크롬 윈도우를 클릭하면 동영상 다운이 중지됩니다.
- 파일 수정 금지: `referer_rules.json`은 네이버 클라우드 서버의 차단을 우회하는 핵심 설정 파일입니다. 절대 수정하거나 삭제하지 마세요.
- 개인 소장용: 본 프로그램은 개인 학습 편의를 위해 제작되었습니다. 다운로드한 영상의 무단 배포로 인한 책임은 사용자에게 있습니다.
